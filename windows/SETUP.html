Open links in the tab you already have

Link Reuse checks your chosen browser before opening an external link. Matching tabs keep their current page and view.

  1. Load the browser extension. In Edge, enter edge://extensions in the address bar. Turn on Developer mode, choose Load unpacked, and select this folder: For Chrome or Brave, use chrome://extensions or brave://extensions. On a managed PC, your organization must allow the extension and local browser helper.
  2. Check the connection. Open the Link Reuse extension popup. It should say it is connected. Website access supports redirect and page-identity learning. Private windows are excluded.
  3. Choose how external links reach Link Reuse.

    To use it directly, run link-reuse --defaults in PowerShell and choose Link Reuse for HTTP and HTTPS. This replaces your default browser setting; pages still open in your chosen browser.

    If you already use a browser router, keep that as your default and add LinkReuse.exe as a custom destination. Pass the URL as one argument, optionally preceded by --browser edge, --browser chrome or --browser brave.

To choose Edge: link-reuse --install --browser edge. Check the bridge: link-reuse --status.

Learning stays in extension memory while matching tabs are open, with a 2 MiB / 4,096-link limit. It is lost when the browser or extension restarts. Previously unseen redirects need a first normal visit.

Before uninstalling, select your real browser as the default. After updating, reload the extension. No administrator privileges, Start menu shortcut or login startup entry is required.
